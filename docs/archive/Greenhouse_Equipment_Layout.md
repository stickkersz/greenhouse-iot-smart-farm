# 🌿 Greenhouse Equipment Layout Design
**โรงเรือน: กว้าง 240cm × ยาว 460cm × สูงสุด 270cm (หลังคาโค้ง)**

---

## 📸 สิ่งที่สังเกตได้จากรูป

| ส่วน | รายละเอียด |
|------|-----------|
| โครงสร้าง | โครงเหล็ก + ฝาอลูมิเนียม |
| ผนัง | ฟิล์มพลาสติกใส PE ทุกด้าน |
| หลังคา | ฟิล์ม PE + ตาข่ายพรางแสง 50% |
| พื้น | คอนกรีต + แผ่นปูพื้น |
| ประตู | ผนังด้านหน้า (กึ่งกลาง) |
| ชั้นวางต้นไม้ | คอนกรีต 3 ชั้น ตลอดแนว ผนังซ้าย |
| ด้านที่ติดตึง | ผนังยาวด้านขวา (ใช้วาง Control Box) |

---

## ⚡ 1. การเดินไฟ (Electrical Routing)

```
ตึก → [ท่อ PVC 20mm บนผนังตึก] → RCBO 16A 30mA (ใน Control Box)
                                          ↓
                                  Control Box IP65
                               (ติดผนังด้านนอก-ตึก ระดับ 150cm)
                                 │ S-60-12 (12V 5A)
                                 │ LM2596 Buck (12V→5V)
                                 │ ESP32 + 4-Relay Module
                                          ↓
                         [ท่อ PVC 16mm + Grommet กันน้ำ ระดับ 200cm]
                                          ↓
                              เข้าโรงเรือน: DC 12V เท่านั้น
                              + สายเซนเซอร์ (I2C, Analog, 1-Wire)
```

> ⚠️ **ไม่มี 220V AC ภายในโรงเรือนเลย** — ปลอดภัยสูงสุด

## 💧 2. ระบบพ่นหมอก (Misting System)

### การวางสาย (Top View)

```
ผนังซ้าย (bench)
│←70cm→│←────── สาย A ──────→│
│       ①  ②  ③  ④  ⑤  ⑥  ⑦
│              240cm              │
│   ①  ②  ③  ④  ⑤  ⑥  ⑦      │
│←──────── สาย B ────────→│←70cm→│
                                  ผนังขวา (ทางเดิน)
```

| พารามิเตอร์ | ค่า |
|------------|-----|
| จำนวนสาย PE | 2 สาย ขนานกัน |
| สาย A | ห่างผนัง bench 70 cm |
| สาย B | ห่างผนัง bench 170 cm (= ห่างผนังอีกด้าน 70 cm) |
| ระดับความสูงท่อ | **200 cm** (ห้อยจาก purlin หลังคา) |
| หัวฉีดต่อสาย | **7 หัว** |
| รวมหัวฉีด | **14 หัว** |
| ระยะห่างหัวฉีด | ~65 cm (เริ่มห่างผนังหน้า 25cm) |
| หัวฉีด | ทองเหลือง 0.1mm ปรับทิศได้ |
| ความดันทำงาน | 5–8 Bar |

### การเดินท่อน้ำ
- ท่อ PE 6mm จากปั๊ม → ผ่านมุมหลัง-ตึก → เข้าโรงเรือนผ่าน Grommet ระดับ 200cm
- T-connector → แยกเป็นสาย A และ B
- ทั้งสองสายวิ่งตลอดความยาว 460cm ตาม purlin หลังคา

## 💨 3. พัดลม (Fan)

| รายการ | รายละเอียด |
|--------|-----------|
| ตำแหน่ง | **ผนังหลัง (short wall ฝั่งตรงข้ามประตู) กึ่งกลาง** |
| ระดับติดตั้ง | **180 cm** จากพื้น |
| ประเภท | บานเกล็ด Gravity Shutter AC 220V |
| ขนาดแนะนำ | 10 inch |
| การไหลอากาศ | เข้าทางประตู/ช่องว่างด้านหน้า → ออกพัดลมด้านหลัง |
| สายไฟ | 220V จาก Relay CH2 ใน Control Box → ท่อ PVC ติดเฟรมผนังด้านนอก → เข้าพัดลม |

> Gravity Shutter ปิดอัตโนมัติเมื่อพัดลมหยุด → ป้องกันแมลง

## 📡 4. เซนเซอร์ (Sensors)

| เซนเซอร์ | ตำแหน่ง | ระดับสูง | หมายเหตุ |
|---------|---------|---------|---------|
| **SHT40** (T&RH อากาศ) | กึ่งกลางโรงเรือน (L/2 = 230cm จากผนัง) | **150 cm** | ในกล่อง Stevenson Screen ป้องกันละออง |
| **DS18B20** (T น้ำ) | จุ่มในถัง 200L ด้านนอก | ใต้ผิวน้ำ | กันน้ำ IP68 |
| **Capacitive Soil Moisture** | ปักในวัสดุปลูก กลาง bench ชั้นบนสุด | ลึก 5–8 cm | 1 จุด ตัวแทน |

### Stevenson Screen (กล่องป้องกัน SHT40)
- กล่อง PVC/พลาสติกใส ขนาด 8×8×10cm
- เจาะรู 4mm รอบด้าน (อากาศถ่ายเท)
- ห้อยคว่ำ (ด้านเปิดหันลง) ป้องกันน้ำหมอกตกลงไปโดนเซนเซอร์โดยตรง
- ยึดกับ frame เหล็กด้วย cable tie

## ✅ ลำดับการติดตั้ง

1. **วาง Control Box** → ยึดผนังตึก ระดับ 150cm → เดินท่อ PVC 20mm จากแหล่งไฟ
2. **ติด RCBO + PSU** ในกล่อง → ทดสอบแรงดัน
3. **ร้อยท่อ PVC 16mm** จากกล่อง → เข้าโรงเรือนผ่าน Grommet ระดับ 200cm
4. **ติดตั้งท่อมิสติ้ง** บน purlin หลังคา 200cm → ใส่หัวฉีด 14 หัว
5. **วางถังน้ำ + ปั๊ม** นอกโรงเรือน มุมหลัง → ต่อท่อ PE เข้าระบบ
6. **ติดพัดลม** ผนังหลัง ระดับ 180cm → ต่อสาย 220V จาก relay CH2
7. **ติดเซนเซอร์** SHT40 (ระดับ 150cm) + DS18B20 (ในถัง) + Soil (ใน bench)
8. **Wiring ESP32 + Relay** ใน Control Box → Upload firmware
9. **ทดสอบ** เปิดระบบ ตรวจหัวฉีด ตรวจ relay ทุก channel
